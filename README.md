# دروس خاص (Dexoed)

تطبيق Flutter لإدارة الدروس الخاصة: الطلاب، المواعيد، الدروس، المدفوعات، والأرباح — بواجهة عربية (RTL) بالكامل.

## أحدث التحديثات (إصدار 1.7.0)

### 1) إصلاح تصميم الصفحة الرئيسية للمعلم
- إعادة بناء كاملة للواجهة: إزالة شريط التطبيق الشفاف الذي كان يغطي المحتوى، وإضافة بطاقة ترحيب متدرجة (اسم المعلم + التاريخ + الرصيد المتحرك مع زر الوصول للأرصدة).
- صف إحصائيات جديد (الطلاب / الدروس / المنتهية) ببطاقات متجاوبة لا تتكسر مع تكبير الخط أو الشاشات الصغيرة.
- كل المحتوى في قائمة واحدة قابلة للتمرير مع سحب للتحديث، والأقسام (المتكررة، الجارية، أقرب ٣ دروس، المعلقة) أصبحت ببطاقات متوافقة مع الوضع الفاتح والداكن.

### 2) إصلاح تصميم صفحة الأرصدة
- إعادة بناء كاملة: بطاقة إجمالي متدرجة + فلاتر حديثة (الكل / عليهم مستحق / لهم زيادة مدفوعة) بدل أزرار التبديل القديمة.
- إصلاح مشكلتين كانتا تسببان تعليقاً/انهياراً: تحريك الرقم أصبح بـ `TweenAnimationBuilder` بدل استدعاء المتحكم أثناء البناء، وشريط التوزيع أصبح بعروض محسوبة بدل `Expanded(flex: 0)`.
- بطاقة الطالب: صورة حرفية ملوّنة، آخر دفعة مسجلة، مجموع الدروس والمدفوع، زر دفع، والضغط على البطاقة يفتح دروس الطالب مباشرة.

### 3) سجل الدروس: فرز حسب التاريخ + فلترة الدفع
- زر ترتيب في الشريط العلوي (الأحدث أولاً / الأقدم أولاً) + خيار الترتيب داخل لوحة الفلاتر.
- تجميع الدروس تحت عناوين التاريخ الحقيقية (اليوم • الاثنين 2026-08-24 …) مع عدد دروس كل يوم.
- تبويب جديد «💳 الدفع» في لوحة الفلاتر:
  - **غير المدفوعة**: توزيع صافي مدفوعات الطالب على دروسه المنتهية من الأقدم للأحدث — الدرس غير المُغطّى يظهر بشارة «غير مدفوع» الحمراء.
  - **منذ آخر دفعة**: الدروس المنتهية التي وقعت بعد آخر دفعة سجّلها الطالب (طالب لم يدفع إطلاقاً → كل دروسه المنتهية).
- شارة «مدفوع / غير مدفوع» على كل درس منتهي وداخل تفاصيله، وشريط ملخص يعرض إجمالي غير المدفوع وعدده.

## التحديثات السابقة (إصدار 1.6.0)

### 1) إعادة تصميم شاملة
- نظام تصميم موحّد جديد `lib/src/theme/app_theme.dart` قائم على Material 3 (ألوان مشتقة من لون أساسي واحد، بطاقات وحقول وأزرار بحواف موحّدة، دعم كامل للوضع الفاتح/الداكن).
- صفحة تسجيل دخول جديدة كلياً بمربّعات كود متجاوبة وشاشة إقلاع (Splash) أنيقة.
- صفحة **الملف الشخصي للمعلم** الجديدة (`teacher_profile_page.dart`): بيانات الحساب + إحصائيات (الطلاب، الدروس المنتهية، الدروس القادمة، أرباح الشهر والإجمالي) + اختيار المظهر + تسجيل الخروج.
- توحيد التدرّج اللوني في القوائم الجانبية للمعلم والطالب.

### 2) حذف منطق التحقق من البريد الإلكتروني بالكامل
- حُذفت الصفحات والخدمات: `verify_email_page.dart`, `add_email_page.dart`, `otp_input.dart`, `supabase_mailer.dart`, ودالة Supabase `send-email`.
- أُزيلت الحقول `verified` و`verificationCode` من نموذج المستخدم ومن قاعدة البيانات ومن بوابة الدخول.
- البريد الإلكتروني أصبح معلومة اختيارية للتواصل فقط.
- أُزيلت الحزم غير المستخدمة: `mailer`, `supabase_flutter`.

### 3) ميزة جديدة للمعلم: إضافة درس منتهي
`lib/src/pages/teacher_add_ended_lesson_page.dart`
- تسجيل درس تمّ إعطاؤه سابقاً ولم يُسجَّل في التطبيق.
- اختيار الطالب، التاريخ، وقت البداية/النهاية، أو مدة جاهزة (30/45/60/90/120 دقيقة).
- حساب المبلغ تلقائياً من **سعر ساعة الطالب** مع إمكانية تعديله يدوياً.
- إضافة أكثر من درس دفعة واحدة + ملاحظة لكل درس.
- يُحفظ الدرس بحالة `ended` (يدخل مباشرة في الرصيد وسجل الدروس) **بدون إنشاء أي تنبيهات**.
- الوصول إليه من: زر عائم في الصفحة الرئيسية، القائمة الجانبية، وأيقونة في سجل الدروس.

### 4) تسجيل دخول سريع وبدون تحليل للدروس
- **لم يعد تسجيل الدخول يحلّل الدروس ولا ينشئ تنبيهات** (تمت إزالة `bootstrapAfterLogin` من مسار الدخول).
- إعادة جدولة التنبيهات أصبحت **يدوية**: من القائمة الجانبية → «إعادة جدولة التنبيهات»، أو تلقائياً عند حفظ إعدادات المنبهات.
- الإقلاع: `Firebase` فقط قبل `runApp`، أما تهيئة الإشعارات فتتم في الخلفية.
- الجلسة تُقرأ من التخزين المحلي (بدون شبكة) → فتح التطبيق شبه فوري.
- التحقق من وجود مدير أصبح باستعلام مُفهرس + كاش محلي + مهلة قصوى.
- فحص الأذونات (البطارية/التنبيهات الدقيقة) انتقل إلى ما بعد ظهور الشاشة الرئيسية بدل تعطيل الإقلاع.

### 5) توافق كامل مع الهاتف
- تثبيت اتجاه RTL على مستوى التطبيق وتحديد نطاق تكبير الخط (0.85 – 1.25) لمنع كسر التصميم.
- أدوات تجاوب جديدة `lib/src/theme/responsive.dart` (هوامش، أعمدة شبكة، عرض أقصى للمحتوى، تحجيم النص).
- بطاقات الإحصائيات في الصفحة الرئيسية أصبحت بارتفاع متجاوب مع حجم الشاشة وحجم الخط.
- كل الصفحات الجديدة قابلة للتمرير وتتكيّف مع الشاشات الصغيرة ولوحة المفاتيح.
- إصلاح مسارات ناقصة كانت تسبب أخطاء عند الضغط على بطاقات «الطلاب» و«الدروس» (`/teacher_students`, `/teacher_schedule`, `/teacher_lessons`, `/teacher_balance`).
- تسجيل الخروج يمسح مكدس الصفحات بالكامل في كل الأدوار.

```
    ├── models/               # AppUser + الأدوار
    ├── pages/                # صفحات المعلم/الطالب/المدير
    ├── providers/            # AuthProvider + ThemeProvider
    ├── services/             # الإشعارات، المنبهات، PDF، التكرار
    ├── theme/                # AppTheme + أدوات التجاوب
    ├── ui/                   # شاشات المنبه
    └── widgets/              # القوائم الجانبية
```
